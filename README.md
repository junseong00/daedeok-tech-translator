## 서비스 개요

대덕연구개발특구에 축적된 사업화 공개기술 1,451건(2022~2024년 공개 전수)을, 전문 지식이 없는 대학생과 예비 청년창업자가 검색 한 번으로 이해하고 창업 아이디어로 연결할 수 있게 "번역"해 보여주는 셀프서브 웹 서비스입니다.

사용자가 관심 분야나 문제의식(예: `반려동물`, `친환경`, `전기차 충전`)을 자유롭게 입력하면 관련 공개기술이 목록으로 나오고, 항목을 열면 기술 개요와 시장 전망, 기술성숙도, 문의할 수 있는 기관까지 한 화면에서 확인할 수 있습니다.

별도 서버 없이 정적 파일만으로 동작하므로, 접속 즉시 1,451건 전체를 검색할 수 있습니다.

## 무엇을 하는가

각 기술 항목은 세 가지 원칙으로 구성됩니다.

1. **기술 설명은 원문 그대로 인용합니다.** 요약·재작성·생성을 하지 않습니다. 생성형 요약은 기술 역량을 부풀릴 위험이 있어, 정보 신뢰성을 위해 원본 문장만 표시합니다.
2. **전문가용 지표인 TRL을 3단계로 번역합니다.** 학생이 "이 기술로 지금 무엇을 할 수 있는 단계인지"를 바로 판단할 수 있게 합니다. 배지와 함께 2~9단계 사다리 위 위치로도 보여줍니다.
3. **문의처까지 연결합니다.** 대덕 소재 기관 111곳을 유형별로 정리해 안내합니다.

### TRL 번역 규칙

| 원본 TRL | 화면 표시 | 건수 |
|---|---|---:|
| 7 ~ 9 | 지금 시작 가능 | 35 |
| 6 | 공동연구 검토 | 102 |
| 2 ~ 5 | 아직 이르다 · 장기 관찰 | 1,250 |
| 값 없음 | 성숙도 미공개 | 64 |

공개기술의 **86%가 TRL 2~5(개념~실험실)** 단계입니다. 이 사실을 감추거나 낙관적으로 포장하지 않고, 분포 막대로 화면 상단에 먼저 보여줍니다.

## 왜 필요한가

**청년 창업의 정보 비대칭이 문제입니다.** 예비 청년창업자 대부분은 아이디어를 백지에서 시작합니다. 그러나 대덕특구에는 전국 특구 중 가장 큰 기술 자산이 쌓여 있습니다. 누적 기술이전 2,057건, 기술이전료 1,397억 원으로 전체 특구 중 1위이며, 2위인 강소특구(562억 원)의 두 배가 넘습니다. 검증된 기술 자산은 있는데 학생과 예비창업자가 여기에 접근할 실질적인 채널이 없다는 것이 이 서비스가 해결하려는 문제입니다.

**비어 있는 자리에 들어갑니다.** 국가기술은행(NTB)과 특구 사업화포털은 전문가·기업을 대상으로 한 B2B 검색 환경이고, "공공기술기반 창업탐색 지원사업" 같은 프로그램은 신청해서 선발되어야 참여할 수 있는 코호트형입니다. 신청하지 않아도, 전문 연구자가 아니어도, 누구나 검색 한 번으로 기술을 열람하는 셀프서브 웹 서비스는 확인되지 않았습니다.

**왜곡 없이 번역합니다.** 생성형 AI로 기술 설명을 다시 쓰면 기술 역량이 부풀려질 수 있습니다. 이 서비스는 기술 개요 원문을 그대로 인용하고, 규칙 기반의 TRL 번역만 덧붙입니다. 실제 데이터에서 초기 단계가 86%임을 확인했고, 이를 숨기지 않고 "공동연구 검토 · 장기 관찰"로 정직하게 표시합니다.

**열람에서 실행으로 잇습니다.** 기술을 확인한 사용자가 대덕 소재 기관 111곳의 문의 창구까지 도달할 수 있도록 안내합니다.

### 정성

- **청년 창업 정보 격차 해소** — 전문가만 읽을 수 있던 공공 기술 정보를 학생 눈높이로 열어, 창업 준비의 출발선을 낮춥니다.
- **"대전엔 할 게 없다"는 통념에 대한 반박** — 대덕의 정부출연연구기관 27곳과 축적된 기술 자산을 눈에 보이게 만들어, 지역에 남을 이유를 구체적인 기술 목록으로 제시합니다.
- **공공데이터 활용 모델 제시** — 포털에 공개만 되어 있던 특구재단 데이터 4종을 결합해 실사용 서비스로 전환한 사례를 남깁니다.
- **출연연 기술사업화 저변 확대** — 연구기관 입장에서도 기술 수요자 접점이 기업에서 청년층으로 넓어집니다.

## 이 서비스가 하지 않는 것

솔직하게 적어 둡니다. 데이터의 한계를 숨기면 서비스의 신뢰도가 먼저 무너집니다.

- **문의처 기관은 개별 기술과 매칭한 결과가 아닙니다.** 원본 데이터에 기관과 기술을 잇는 키가 없습니다. 대덕 소재 기관 목록을 유형별로 정리해 참고용으로만 제공합니다.
- **연구소기업 수치는 지역 전체의 추세이며 특정 기술의 성공 사례가 아닙니다.** 어떤 기술에서 어떤 회사가 나왔는지 연결하는 항목이 원본에 없습니다.
- **원본 데이터에 입력 오류가 있습니다.** 23번째 항목은 기술명과 기술 개요의 주제가 서로 다릅니다. 임의로 고치지 않고, 화면에 경고 문구와 함께 원문 그대로 표시합니다.
- **검색은 키워드 기반입니다.** 정적 사이트로 배포하기 위해 형태소 분석기나 임베딩 모델 없이, 부분일치와 글자 바이그램 유사도로 검색합니다. 여러 단어를 입력하면 모든 단어를 포함한 기술이 상위에 오도록 커버리지를 반영합니다.
- **다루는 범위는 2022~2024년 공개분 전수입니다.** 대덕특구의 모든 기술이 아니라, 특구재단이 공개한 사업화 기술 1,451건입니다.

## 실행 방법

```bash
# 1. 공공데이터 4종 내려받기 (로그인 불필요)
bash download.sh raw

# 2. CSV -> data/data.json 변환
python3 build_data.py raw

# 3. 로컬 확인
python3 -m http.server 8000
```

정적 파일만으로 동작하므로 별도 서버가 필요 없습니다. GitHub Pages로 배포합니다.
