# 청년 기술창업 번역 플랫폼

대덕특구에 잠들어 있는 **사업화 공개기술 1,451건**을, 창업을 고민하는 대학생이 읽을 수 있게 번역해 보여주는 웹 서비스입니다.

2026년도 공공데이터 활용 공모전 · 웹/앱 개발 분야 · 연구개발특구진흥재단
팀 **일했음청년** — 국립한밭대학교 컴퓨터공학과 박준성 · 김주희 · 노도원

## 무엇을 하는가

관심 분야나 문제의식(예: `반려동물`, `친환경 포장`, `제조 자동화`)을 입력하면 관련 공개기술을 카드로 보여줍니다. 각 카드는 세 가지 원칙으로 구성됩니다.

1. **기술 설명은 원문 그대로 인용합니다.** 요약·재작성·생성을 하지 않습니다. 생성형 요약은 기술 역량을 부풀릴 위험이 있어, 정보 신뢰성을 위해 원본 문장만 표시합니다.
2. **전문가용 지표인 TRL을 3단계로 번역합니다.** 학생이 "이 기술로 지금 무엇을 할 수 있는 단계인지"를 바로 판단할 수 있게 합니다.
3. **문의처까지 연결합니다.** 대덕 소재 기관 111곳을 실행 파트너 안내로 제공합니다.

### TRL 번역 규칙

| 원본 TRL | 화면 표시 | 건수 |
|---|---|---:|
| 7 ~ 9 | 지금 시작 가능 | 35 |
| 6 | 공동연구 검토 | 102 |
| 2 ~ 5 | 아직 이르다 · 장기 관찰 | 1,250 |
| 값 없음 | 성숙도 미공개 | 64 |

공개기술의 **88.6%가 TRL 3~5(실험실~시작품)** 단계입니다. 이 사실을 감추거나 낙관적으로 포장하지 않고 그대로 표시합니다.

## 이 서비스가 하지 않는 것

솔직하게 적어 둡니다. 데이터의 한계를 숨기면 서비스의 신뢰도가 먼저 무너집니다.

- **실행 파트너 기관은 개별 기술과 매칭한 결과가 아닙니다.** 원본 데이터에 기관과 기술을 잇는 키가 없습니다. 대덕 소재 기관 목록을 문의처 참고용으로만 제공합니다.
- **연구소기업 수치는 지역 전체의 추세이며 특정 기술의 성공 사례가 아닙니다.** 어떤 기술에서 어떤 회사가 나왔는지 연결하는 항목이 원본에 없습니다.
- **원본 데이터에 입력 오류가 있습니다.** 23번째 항목은 기술명과 기술 개요의 주제가 서로 다릅니다. 임의로 고치지 않고, 화면에 경고 문구와 함께 원문 그대로 표시합니다.
- **검색은 키워드 기반입니다.** 정적 사이트로 배포하기 위해 형태소 분석기나 임베딩 모델 없이, 부분일치와 글자 바이그램 유사도로 검색합니다. 여러 단어를 입력하면 모든 단어를 포함한 기술이 상위에 오도록 커버리지를 반영합니다.
- **다루는 범위는 2022~2024년 공개분 전수입니다.** 대덕특구의 모든 기술이 아니라, 특구재단이 공개한 사업화 기술 1,451건입니다.

## 실행 방법

```bash
# 1. 공공데이터 4종 내려받기 (로그인 불필요)
bash download.sh raw

# 2. CSV -> data/data.json 변환
python3 build_data.py raw

# 3. 로컬 확인
python3 -m http.server 8000
```

정적 파일만으로 동작하므로 별도 서버가 필요 없습니다. GitHub Pages로 배포합니다.

## 구조

```
index.html       화면 · 검색 · 상세 (의존성 없는 단일 파일)
build_data.py    공공데이터 CSV(cp949) -> data/data.json
download.sh      공공데이터포털에서 원본 4종 내려받기
data/data.json   기술 1,451건 + 파트너 111곳 + 맥락 지표
```
